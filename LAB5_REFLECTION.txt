URLSession's dataTask and Retrofit's enqueue() both send asynchronous requests so the interface remains responsive while waiting for a response. URLSession returns data, response, and error to one completion handler, whereas Retrofit separates successful responses and failures into onResponse() and onFailure(). Swift's Codable models and JSONDecoder serve a similar purpose to Gson's fromJson(), turning JSON into typed objects while exposing decoding failures. After decoding, Campus Companion replaces and saves its Core Data records, then updates UIKit on the main thread so repeated refreshes do not create duplicate announcements.
